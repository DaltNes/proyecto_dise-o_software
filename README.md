# 🔄 FileConverter Pro

**Conversor Universal de Archivos y Visualizador de Formatos Especiales**

## 📋 Descripción del Proyecto

FileConverter Pro es una aplicación web que resuelve el problema común de **no poder convertir archivos entre diferentes formatos** o **abrir archivos con extensiones poco comunes**. 

### 🎯 Problema que Resuelve
- **Conversión de archivos**: Convierte entre múltiples formatos (.zip ↔ .rar, .pdf ↔ .docx, etc.)
- **Archivos difíciles de abrir**: Visualiza y convierte archivos con extensiones raras (.arc, .lzh, .z, etc.)
- **Centralización**: Una sola plataforma para todas las necesidades de conversión

### ✨ Funcionalidades Principales
- 🔐 Sistema de autenticación seguro
- 📁 Conversión entre múltiples formatos de archivo
- 👁️ Visualización de archivos con extensiones poco comunes
- 📱 Interfaz responsive (móvil, tablet, desktop)
- 🌍 Soporte multilenguaje (Español/Inglés)
- 📊 Historial de conversiones personalizadas
- ☁️ Integración con APIs de conversión profesionales

## 🛠️ Tecnologías Utilizadas

### Frontend
- **React 19.2.0** - Interfaz de usuario moderna
- **Axios** - Cliente HTTP para APIs
- **i18next** - Internacionalización
- **CSS Responsive** - Diseño adaptable

### Backend
- **Node.js + Express** - Servidor API
- **Multer** - Manejo de uploads
- **CORS** - Configuración de seguridad

### Base de Datos & Servicios
- **Supabase** - Base de datos y autenticación
- **API Externa** - Servicio de conversión de archivos

## 📦 Formatos Soportados

### Compresión
- ZIP ↔ RAR ↔ 7Z
- TAR ↔ GZ ↔ BZ2
- ARC, LZH, Z (visualización)

### Documentos
- PDF ↔ DOCX ↔ TXT
- XLSX ↔ CSV ↔ JSON

### Imágenes
- PNG ↔ JPG ↔ WEBP
- SVG ↔ PDF

## 🚀 Instalación y Uso

### Prerrequisitos
- Node.js 16+
- npm o yarn

### Instalación
```bash
# Clonar repositorio
git clone https://github.com/DaltNes/proyecto_diseno_software.git

# Instalar dependencias del backend
cd backend
npm install

# Instalar dependencias del frontend
cd ../frontend
npm install
```

### Configuración
1. Crear cuenta en [Supabase](https://supabase.com)
2. Configurar variables de entorno (ver `.env.example`)
3. Obtener API key para servicio de conversión

### Ejecución
```bash
# Terminal 1: Backend
cd backend
npm start

# Terminal 2: Frontend  
cd frontend
npm start
```
